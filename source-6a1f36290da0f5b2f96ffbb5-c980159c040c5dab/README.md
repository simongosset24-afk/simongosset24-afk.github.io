# Casa Calypso

Presentation website for **Casa Calypso**, a tropical vacation rental in Costa Rica.

## About

A single-page marketing site showcasing the property with sections for key features, photo gallery, about/location details, guest testimonials, and a booking call-to-action.

## Tech Stack

- **Framework**: TanStack Start (SSR React)
- **Routing**: TanStack Router (file-based)
- **Styling**: Tailwind CSS v4 + custom CSS
- **Fonts**: Cormorant Garamond (headings) + DM Sans (body) via Google Fonts
- **Deploy**: Netlify

## Local Development

```bash
npm install
npm run dev       # starts on http://localhost:3000
```

Or with Netlify CLI for full platform emulation:

```bash
netlify dev --port 8889
```

## Deployment

Push to your Git remote — Netlify picks it up automatically and builds with `npm run build`.
